# QuizAPI

> QuizAPI is a developer-first quiz platform with a REST API for creating, sharing, and embedding quizzes. Features include AI-powered quiz generation, leaderboards, gamification, live multiplayer quizzes, and embeddable widgets.

## API Overview

QuizAPI provides a REST API for programmatic quiz management:
- Create and manage quizzes via API
- Fetch questions with filtering by category, difficulty, and tags
- Embed quizzes in any website with an iframe widget
- Track scores and leaderboard entries
- Generate quizzes with AI from any topic

For full API documentation, visit https://quizapi.io/docs
